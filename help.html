快速上手

5 步完成从户型建图、精准排砖到施工图与报价单输出。

1

创建或导入户型

按 W 直接画墙（绘制时直接输入数字回车即可定长），墙体闭合后自动识别房间；也可通过「工程 → 识图建图」上传户型图自动提取墙体、门窗与房间名，或导入参考底图描图。

2

放置门窗与校准尺寸

按 D 放置门洞、F 放置窗洞，选中门可配置通铺 / 过门石 / 压边条衔接方式及入户门标记。双击任意墙体尺寸标注即可精准改长或标定全图比例。

3

配置地面砖材与起铺点

点击任意房间，在左侧切换瓷砖 / 木地板、选择或新增自定义花色（支持预设默认尺寸与编号规则）、选择铺法（正铺 / 工字 / 369 / 45°斜铺）。点击AI 全屋优排可一键优化全屋起铺点以减少小角裁切。

4

切换立面设计墙砖与踢脚线

在顶部切换「立面」或直接点击右侧 3D 轴测预览 中的任意墙面进入立面模式，配置墙砖铺贴范围（离地 / 离顶）、起铺点与瓷砖/木质踢脚线，自动扣减门窗洞口面积。

5

生成报价单与导出施工图纸

右侧「用量汇总」实时计算主材采购量、美缝、辅料、过门石与压边条；点击生成报价导出 Excel / PDF 报价单，或在顶部「导出」菜单输出高清彩图 JPG、A4 施工 PDF、AutoCAD DXF / DWG 及 Excel 明细表。

核心功能详解

了解常用进阶技巧，提升出图与算量效率。

户型绘制与多楼层管理

  • 精确画墙与改长：画墙过程中直接键入毫米数值按 Enter 定长；双击墙体标注线可选择单侧或两端对称伸缩，斜墙支持一键摆直。
  • 多楼层与透显底层：点击画布左下角楼层图标可开启多层管理，支持新建/复制楼层、透显下层墙体轮廓对齐上下层结构，以及一键左右/上下镜像户型。
  • 门洞过门衔接：相邻空间自动判断砖砖/砖木/木木场景，支持通铺（跨门洞共用起铺点不断缝）、过门石、压边条（默认 20mm 偏移且按边缘对齐）；最外墙门可开启入户门标记。

花色库、砖号与算量口径

  • 自定义花色库：上传贴图经裁剪后保存至本地，可为花色预设默认尺寸、材料类型、编号前缀与后缀；选中花色时自动带入默认值，仍可在左侧面板单独覆盖。
  • 统一砖号规则：编号格式为 前缀 + 规格号 + 分隔符 + 序号（如 CT1-1），可在「砖材 → 规格编号 → 设置图标」中修改，地砖/墙砖跨房间自动顺延。
  • 精准算量：支持裁切余料复用统计，右侧用量表与报价单统一按含损耗采购量核算，涵盖主材、踢脚线、过门石、压边条、美缝剂及粘结/防潮垫辅料。

视图控制与图纸导出

  • 底部快捷显示开关：一键控制铺贴预览、砖号与裁切尺寸、门扇显隐、空间标签、起铺点标靶、尺寸标注、指北针、背景网格与网格吸附，地面与立面模式同步生效。
  • 高清彩图导出：平面模式下可导出全屋或单空间铺贴彩图（带四周双层标注与底部图例）；立面模式下自动导出当前空间的展开立面或单墙面高清彩图。
  • CAD / PDF 施工图与自定义图框：支持导出纯离线生成的 DXF / DWG / PDF 施工图（含总平、分空间排砖、墙面立面与末页材料总表），可通过「导出 → 图框设置」自由编辑企业图签。
