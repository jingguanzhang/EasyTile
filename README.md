## 项目简介

**EasyTile（易贴）** 是一款专为建材门店、铺贴师傅与室内设计师打造的纯前端 Web 工作站。项目基于原生 HTML5 Canvas + JavaScript 构建，所有户型识别（ONNX Runtime Web / PP-OCRv5）、几何排砖计算、花色贴图管理（IndexedDB）以及 DXF / DWG / PDF / Excel 图纸导出均在浏览器本地完成，无需后端服务器即可开箱运行。

## 核心功能

### 1. 户型绘制与识图建图
- **交互式画墙与定长**：支持正交/角度吸附、画墙过程直接输入毫米数值回车定长；墙体闭合后自动拓扑识别房间闭合区域。
- **精准改长与比例校准**：双击任意墙体尺寸标注可按“固定起点 / 固定终点 / 两端对称”伸缩墙体，或输入实测长度一键标定全屋比例。
- **户型图自动识别（端侧 OCR + 矢量化）**：内置 ONNX Runtime Web（WASM / WebGPU）与 PP-OCRv5 模型，上传户型图即可在浏览器本地提取墙体、门窗洞口、房间名称及尺寸文字；也支持导入参考底图描图。
- **门窗与过门衔接**：支持单开门、双开门、推拉门、门洞及窗户；门洞支持 **通铺**（跨空间共用起铺网格不断缝）、**过门石**、**压边条** 及 **入户门标记**。
- **多楼层与镜像管理**：支持新建/复制/切换多楼层、透显下层墙体轮廓对齐结构，以及一键左右/上下镜像全屋户型。

### 2. 地面与墙面立面排砖
- **多材质与多铺法**：涵盖 **瓷砖、木地板、墙板、吊顶** 等材质品类，支持 **正铺、工字铺、369 错位铺、45° 斜铺** 及留缝宽度调节。
- **交互式起铺点与 AI 全屋优排**：支持九宫格快捷定起铺点、画布直接拾取起铺点（`O`），以及 **AI 全屋优排**（自动搜索减少碎砖与小角裁切的最优起铺偏移）。
- **墙面立面与 3D 轴测联动**：右侧实时渲染 **3D 轴测预览**，点击任意墙面即可进入立面模式，配置墙砖铺贴高度（离地/离顶）、起铺点与瓷砖/木质踢脚线，自动扣减门窗洞口面积。

### 3. 自定义花色库与统一砖号
- **本地自定义花色库**：支持上传原图并按砖材长宽比例交互式裁剪（基于 Cropper.js），保留原始大图以便二次重新裁剪；支持为花色预设默认尺寸、品类与编号前缀/后缀。
- **自动编号与余料复用**：按 `前缀 + 规格号 + 分隔符 + 序号`（如 `CT1-1`）跨房间自动顺延编号，精确统计整砖、裁切砖、余料复用与损耗采购量。

### 4. 报价单与施工图纸导出
- **实时用量与独立报价工作台**：实时汇总各空间主材、踢脚线、过门石、压边条、美缝剂与粘结辅料，内置独立报价单页面（[`quote.html`](./quote.html)）支持单价编辑及导出 Excel / PDF 报价单。
- **多格式施工图纸输出**：
  - **高清铺贴彩图（JPG）**：支持全屋总平、单空间排砖、空间展开立面及单墙面高清彩图（含双层尺寸标注与图例表）。
  - **A4 施工图册（PDF）**：含封面/总平、分空间地面排砖图、墙面立面图与材料汇总清单。
  - **AutoCAD 施工图（DXF / DWG）**：纯前端矢量生成（内置 `acadrust-wasm` 离线转换 DWG），支持通过图框编辑器（[`tukuan.html`](./tukuan.html)）自定义企业图签。
  - **Excel 用量明细表（`.xlsx`）**：基于 ExcelJS 导出分空间、分花色采购算量表。

## 本地运行

由于项目加载了 WebAssembly（`.wasm`）、ONNX 权重（`weight/*.onnx`）以及本地 JSON 数据，请通过任意静态 HTTP 服务器启动（不要直接双击 `file://` 打开）：

### 方式一：使用 Node.js

```bash
npx serve . -l 8080
```

### 方式二：使用 Python

```bash
python -m http.server 8080
```

### 方式三：使用 VS Code Live Server
在 VS Code 中安装 **Live Server** 插件，右键 [`index.html`](./index.html) 选择 **Open with Live Server** 即可在浏览器中访问 `http://localhost:8080`。

> **提示**：若仅部署基础画图、排砖与 CAD/PDF 导出功能而无需“识图建图（OCR）”，可按需裁剪 `weight/` 目录；如需使用识图建图，请确保 `weight/det.onnx` 与 `weight/rec.onnx` 保持在站点根路径下的 `weight/` 目录中。

## 工程文件格式（`.tcalc`）

EasyTile 使用 `.tcalc`（基于 JSON 的开放结构化工程文件）保存完整项目状态，包括：
- 多楼层墙体节点、墙厚、门窗洞口与过门衔接配置；
- 各空间地面与各墙面立面的铺贴材质、规格、铺法、留缝、起铺点及踢脚线参数；
- 用户上传的自定义花色原图与裁剪参数（自动内嵌序列化，跨设备打开不丢失贴图）；
- 施工图图框参数与报价单配置。

可直接在工作站顶部「工程 → 打开工程」中选择 `.tcalc` 文件，或将 `.tcalc` 文件直接拖入浏览器画布窗口打开。
